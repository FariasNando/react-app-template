## [0.1.0] - 2025-06-02

### Added
- App de Assistência Técnica Franke para VTEX IO.
- Busca de assistências técnicas por CEP ou Estado/Cidade.
- Seleção de produto para filtrar resultados.
- Exibição de resultados detalhados (nome, endereço, telefone, e-mail, etc).
- Skeleton de carregamento, mensagens de erro e sem resultado.
- Integração com Masterdata, API de CEP VTEX e IBGE.
- Interface responsiva, acessível e otimizada.
- Configuração de produtos via Site Editor.
- Documentação e exemplos de uso.
